As Expo doesn't officially support Mac apps through EAS, we have to implement our own distribution logic.

## Via the Xcode GUI

The easiest way is to:

1. Open `macos/MyApp.xcworkspace`.
2. Select the `MyApp-macOS` target.
3. Enable `Automatically manage signing` if not yet enabled.
   Or, if you'd prefer to use manual signing, you'll need to specify a `Provisioning Profile` and `Signing Certificate`.
4. Select your `Team` (the Development Team ID).
   If this is not visible, first click `Add account…` if present, and log in to your Apple Developer ID.
5. Set `Signing Certificate` to `Development`.
6. Run `Product > Archive…`.

The interactive command is the simplest, but inconvenient for CI and agents, as it will prompt you to sign in.

```sh
xcodebuild archive \
  -workspace macos/MyApp.xcworkspace \
  -scheme MyApp-macOS \
  -configuration Release \
  -destination 'generic/platform=macOS' \
  -archivePath "$PWD/dist/MyApp.xcarchive" \
  -allowProvisioningUpdates \
  CODE_SIGN_STYLE=Automatic \
  DEVELOPMENT_TEAM=ABCDE12345
```

To use manual codesigning instead of automatic, specify a provisioning profile and signing certificate:

```diff
  xcodebuild archive \
    -workspace macos/MyApp.xcworkspace \
    -scheme MyApp-macOS \
    -configuration Release \
    -destination 'generic/platform=macOS' \
    -archivePath "$PWD/dist/MyApp.xcarchive" \
    -allowProvisioningUpdates \
-   CODE_SIGN_STYLE=Automatic \
+   CODE_SIGN_STYLE=Manual \
+   CODE_SIGN_IDENTITY="Apple Distribution: Example Company (ABCDE12345)" \
+   PROVISIONING_PROFILE_SPECIFIER="MyApp Mac App Store" \
    DEVELOPMENT_TEAM=ABCDE12345
```

</EnvironmentContent>

<EnvironmentContent interaction="non-interactive">

## Via Fastlane

A full introduction to [Fastlane](https://fastlane.tools) is out of scope for this article, but below is a sample `Fastfile` you could use for distributing a Mac app.

You'd run it with:

```sh
MAC_APPLE_TEAM_ID=ABCDE12345
MAC_APP_STORE_PROFILE=MyApp Mac App Store
MAC_APP_SIGNING_IDENTITY=Apple Distribution: Example Company (ABCDE12345)
MAC_INSTALLER_SIGNING_IDENTITY=Apple Distribution: Example Company (ABCDE12345)
APP_STORE_CONNECT_API_KEY_PATH=/path/to/AuthKey_KEYID.p8

bundle exec fastlane mac release
```

```ruby name="fastlane/Fastfile"
require "xcodeproj"

def infer_macos_release_config(app_root: File.expand_path("..", __dir__))
  macos_root = File.join(app_root, "macos")
  projects = Dir.glob(File.join(macos_root, "*.xcodeproj"))
  UI.user_error!("Expected exactly one macos/*.xcodeproj") unless projects.one?

  project_path = projects.first
  app_name = File.basename(project_path, ".xcodeproj")
  workspace_path = File.join(macos_root, "#{app_name}.xcworkspace")
  scheme_name = "#{app_name}-macOS"
  scheme_path = File.join(project_path, "xcshareddata", "xcschemes", "#{scheme_name}.xcscheme")
  configuration = Xcodeproj::XCScheme.new(scheme_path).archive_action.build_configuration

  project = Xcodeproj::Project.open(project_path)
  target = project.targets.find { |item| item.name == scheme_name }
  UI.user_error!("Missing target #{scheme_name}") unless target

  build_configuration = target.build_configurations.find { |item| item.name == configuration }
  UI.user_error!("Missing build configuration #{configuration}") unless build_configuration
  bundle_id = build_configuration.resolve_build_setting("PRODUCT_BUNDLE_IDENTIFIER", target)
  UI.user_error!("PRODUCT_BUNDLE_IDENTIFIER is missing") if bundle_id.to_s.empty?

  {
    app_root: app_root,
    project_path: project_path,
    workspace_path: workspace_path,
    scheme_name: scheme_name,
    target_name: target.name,
    configuration: configuration,
    bundle_id: bundle_id,
    team_id: build_configuration.resolve_build_setting("DEVELOPMENT_TEAM", target),
    profile_name: build_configuration.resolve_build_setting("PROVISIONING_PROFILE_SPECIFIER", target)
  }
end

platform :mac do
  lane :release do
    inferred = infer_macos_release_config

    # Signing: use configured project values unless explicitly overridden.
    team_id = ENV["MAC_APPLE_TEAM_ID"] || inferred[:team_id]
    profile_name = ENV["MAC_APP_STORE_PROFILE"] || inferred[:profile_name]
    UI.user_error!("Configure macos.appleTeamId and prebuild, or set MAC_APPLE_TEAM_ID") if team_id.to_s.empty?
    UI.user_error!("Configure a distribution profile, or set MAC_APP_STORE_PROFILE") if profile_name.to_s.empty?

    # Distribution certificate selection and upload credentials remain explicit.
    app_identity = ENV.fetch("MAC_APP_SIGNING_IDENTITY")
    installer_identity = ENV.fetch("MAC_INSTALLER_SIGNING_IDENTITY")
    api_key_path = File.expand_path(ENV.fetch("APP_STORE_CONNECT_API_KEY_PATH"), inferred[:app_root])
    UI.user_error!("App Store Connect API key JSON not found: #{api_key_path}") unless File.file?(api_key_path)

    update_code_signing_settings(
      path: inferred[:project_path],
      targets: [inferred[:target_name]],
      build_configurations: [inferred[:configuration]],
      use_automatic_signing: false,
      team_id: team_id,
      code_sign_identity: app_identity,
      profile_name: profile_name
    )

    pkg = build_app(
      workspace: inferred[:workspace_path],
      scheme: inferred[:scheme_name],
      configuration: inferred[:configuration],
      output_directory: File.join(inferred[:app_root], "dist"),
      export_method: "app-store",
      export_team_id: team_id,
      installer_cert_name: installer_identity,
      skip_profile_detection: true,
      export_options: {
        signingCertificate: app_identity,
        provisioningProfiles: { inferred[:bundle_id] => profile_name }
      }
    )

    upload_to_app_store(
      pkg: pkg,
      api_key_path: api_key_path,
      skip_metadata: true,
      skip_screenshots: true,
      submit_for_review: false,
      run_precheck_before_submit: false
    )
  end
end
```
