<EnvironmentContent distribution="store">

The easiest way is to:

1. Open `macos/MyApp.xcworkspace`.
2. Select the `MyApp-macOS` target.
3. Enable `Automatically manage signing` if not yet enabled.
   Or, if you'd prefer to use manual signing, you'll need to specify a `Provisioning Profile` and `Signing Certificate`.
4. Select your `Team` (the Development Team ID).
   If this is not visible, first click `Add account…` if present, and log in to your Apple Developer ID.
5. Set `Signing Certificate` to `Development`.
6. Run `Product > Archive…`.

</EnvironmentContent>

<EnvironmentContent distribution="third-party">

Use [Developer ID distribution](https://developer.apple.com/documentation/xcode/creating-distribution-signed-code-for-the-mac) to export a notarized app for direct download.

1. Open `macos/MyApp.xcworkspace` and select the `MyApp-macOS` scheme.
2. Set the app target's `Team` to your Development Team ID and enable `Hardened Runtime` for the Release configuration.
3. Run `Product > Archive…`, then choose `Distribute App > Direct Distribution` in the Organizer. For custom signing, use `Custom > Developer ID` and select automatic or manual signing. Manual signing takes a `Developer ID Application` identity and, if your entitlements require one, a Developer ID provisioning profile.
4. Once notarization finishes, export the app to `dist/export/MyApp.app`.

Validate the stapled ticket and package the exported app:

```sh
xcrun stapler validate "$PWD/dist/export/MyApp.app"
ditto -c -k --sequesterRsrc --keepParent \
  "$PWD/dist/export/MyApp.app" \
  "$PWD/dist/MyApp.zip"
```

Distribute `dist/MyApp.zip`. The signing identity's private key must be available in your keychain.


<EnvironmentContent interaction="interactive">

Pass your Apple ID and team ID. `notarytool` prompts for the Apple ID's app-specific password:

```sh
xcrun notarytool submit "$PWD/dist/MyApp-notarization.zip" \
  --apple-id APPLE_ID \
  --team-id ABCDE12345 \
  --wait
```

</EnvironmentContent>

<EnvironmentContent interaction="non-interactive">

Pass the same team API key used for the build:

```sh
xcrun notarytool submit "$PWD/dist/MyApp-notarization.zip" \
  --key /path/to/AuthKey_KEYID.p8 \
  --key-id KEYID \
  --issuer ISSUER_UUID \
  --wait
```

</EnvironmentContent>

After the submission reports `Accepted`, staple the ticket to the app and create the final download ZIP. ZIP files cannot be stapled directly.

```sh
xcrun stapler staple "$PWD/dist/export/MyApp.app"
xcrun stapler validate "$PWD/dist/export/MyApp.app"
ditto -c -k --sequesterRsrc --keepParent \
  "$PWD/dist/export/MyApp.app" \
  "$PWD/dist/MyApp.zip"
```

Distribute `dist/MyApp.zip`.

<EnvironmentContent distribution="store">

A full introduction to [Fastlane](https://fastlane.tools) is out of scope for this article, but below is a sample `Fastfile` you could use for distributing a Mac app using Fastlane's [`upload_to_app_store`](https://docs.fastlane.tools/actions/upload_to_app_store/#upload_to_app_store) action.

```ruby name="fastlane/Fastfile"
require "xcodeproj"

platform :mac do
  lane :release do
    inferred = infer_macos_release_config

    # Signing: use configured project values unless explicitly overridden.
    team_id = ENV["MAC_APPLE_TEAM_ID"] || inferred[:team_id]
    profile_name = ENV["MAC_APP_STORE_PROFILE"] || inferred[:profile_name]
    UI.user_error!("Configure macos.appleTeamId and prebuild, or set MAC_APPLE_TEAM_ID") if team_id.to_s.empty?
    UI.user_error!("Configure a distribution profile, or set MAC_APP_STORE_PROFILE") if profile_name.to_s.empty?

    # Distribution certificate selection and upload credentials remain explicit.
    app_identity = ENV.fetch("MAC_APP_SIGNING_IDENTITY")
    installer_identity = ENV.fetch("MAC_INSTALLER_SIGNING_IDENTITY")
    api_key_path = File.expand_path(ENV.fetch("APP_STORE_CONNECT_API_KEY_PATH"), inferred[:app_root])
    UI.user_error!("App Store Connect API key JSON not found: #{api_key_path}") unless File.file?(api_key_path)

    update_code_signing_settings(
      path: inferred[:project_path],
      targets: [inferred[:target_name]],
      build_configurations: [inferred[:configuration]],
      use_automatic_signing: false,
      team_id: team_id,
      code_sign_identity: app_identity,
      profile_name: profile_name
    )

    pkg = build_app(
      workspace: inferred[:workspace_path],
      scheme: inferred[:scheme_name],
      configuration: inferred[:configuration],
      output_directory: File.join(inferred[:app_root], "dist"),
      export_method: "app-store",
      export_team_id: team_id,
      installer_cert_name: installer_identity,
      skip_profile_detection: true,
      export_options: {
        signingCertificate: app_identity,
        provisioningProfiles: { inferred[:bundle_id] => profile_name }
      }
    )

    upload_to_app_store(
      pkg: pkg,
      api_key_path: api_key_path,
      skip_metadata: true,
      skip_screenshots: true,
      submit_for_review: false,
      run_precheck_before_submit: false
    )
  end
end

def infer_macos_release_config(app_root: File.expand_path("..", __dir__))
  macos_root = File.join(app_root, "macos")
  projects = Dir.glob(File.join(macos_root, "*.xcodeproj"))
  UI.user_error!("Expected exactly one macos/*.xcodeproj") unless projects.one?

  project_path = projects.first
  app_name = File.basename(project_path, ".xcodeproj")
  workspace_path = File.join(macos_root, "#{app_name}.xcworkspace")
  scheme_name = "#{app_name}-macOS"
  scheme_path = File.join(project_path, "xcshareddata", "xcschemes", "#{scheme_name}.xcscheme")
  configuration = Xcodeproj::XCScheme.new(scheme_path).archive_action.build_configuration

  project = Xcodeproj::Project.open(project_path)
  target = project.targets.find { |item| item.name == scheme_name }
  UI.user_error!("Missing target #{scheme_name}") unless target

  build_configuration = target.build_configurations.find { |item| item.name == configuration }
  UI.user_error!("Missing build configuration #{configuration}") unless build_configuration
  bundle_id = build_configuration.resolve_build_setting("PRODUCT_BUNDLE_IDENTIFIER", target)
  UI.user_error!("PRODUCT_BUNDLE_IDENTIFIER is missing") if bundle_id.to_s.empty?

  {
    app_root: app_root,
    project_path: project_path,
    workspace_path: workspace_path,
    scheme_name: scheme_name,
    target_name: target.name,
    configuration: configuration,
    bundle_id: bundle_id,
    team_id: build_configuration.resolve_build_setting("DEVELOPMENT_TEAM", target),
    profile_name: build_configuration.resolve_build_setting("PROVISIONING_PROFILE_SPECIFIER", target)
  }
end
```

You'd run it with:

```sh
MAC_APPLE_TEAM_ID=ABCDE12345
MAC_APP_STORE_PROFILE="MyApp Mac App Store"
MAC_APP_SIGNING_IDENTITY="Apple Distribution: Example Company (ABCDE12345)"
MAC_INSTALLER_SIGNING_IDENTITY="Apple Distribution: Example Company (ABCDE12345)"
APP_STORE_CONNECT_API_KEY_PATH="path/to/AuthKey_KEYID.p8"

bundle exec fastlane mac release
```

<EnvironmentContent distribution="third-party">

A full introduction to [Fastlane](https://fastlane.tools) is out of scope for this article, but below is a sample `Fastfile` you could use for distributing a Mac app using Fastlane's [`notarize`](https://docs.fastlane.tools/actions/notarize/) action.

```ruby name="fastlane/Fastfile"
require "xcodeproj"

platform :mac do
  lane :release do
    inferred = infer_macos_release_config

    team_id = ENV["MAC_APPLE_TEAM_ID"] || inferred[:team_id]
    UI.user_error!("Configure macos.appleTeamId and prebuild, or set MAC_APPLE_TEAM_ID") if team_id.to_s.empty?

    app_identity = ENV.fetch("MAC_APP_SIGNING_IDENTITY")
    profile_name = ENV.fetch("MAC_DEVELOPER_ID_PROFILE", "")
    key_path = File.expand_path(
      ENV.fetch("APP_STORE_CONNECT_API_KEY_PATH"),
      inferred[:app_root]
    )

    update_code_signing_settings(
      path: inferred[:project_path],
      targets: [inferred[:target_name]],
      build_configurations: [inferred[:configuration]],
      use_automatic_signing: false,
      team_id: team_id,
      code_sign_identity: app_identity,
      profile_name: profile_name
    )

    export_options = {
      signingStyle: "manual",
      signingCertificate: app_identity
    }
    unless profile_name.empty?
      export_options[:provisioningProfiles] = {
        inferred[:bundle_id] => profile_name
      }
    end

    app = build_app(
      workspace: inferred[:workspace_path],
      scheme: inferred[:scheme_name],
      configuration: inferred[:configuration],
      destination: "generic/platform=macOS",
      output_directory: File.join(inferred[:app_root], "dist"),
      export_method: "developer-id",
      export_team_id: team_id,
      skip_profile_detection: true,
      export_options: export_options,
      xcargs: "ENABLE_HARDENED_RUNTIME=YES"
    )

    notarize(
      package: app,
      api_key: {
        key_id: ENV.fetch("APP_STORE_CONNECT_API_KEY_ID"),
        issuer_id: ENV.fetch("APP_STORE_CONNECT_API_ISSUER_ID"),
        key: File.read(key_path)
      },
      print_log: true
    )

    sh("ditto", "-c", "-k", "--sequesterRsrc", "--keepParent", app, "#{app}.zip")
  end
end

def infer_macos_release_config(app_root: File.expand_path("..", __dir__))
  macos_root = File.join(app_root, "macos")
  projects = Dir.glob(File.join(macos_root, "*.xcodeproj"))
  UI.user_error!("Expected exactly one macos/*.xcodeproj") unless projects.one?

  project_path = projects.first
  app_name = File.basename(project_path, ".xcodeproj")
  workspace_path = File.join(macos_root, "#{app_name}.xcworkspace")
  scheme_name = "#{app_name}-macOS"
  scheme_path = File.join(project_path, "xcshareddata", "xcschemes", "#{scheme_name}.xcscheme")
  configuration = Xcodeproj::XCScheme.new(scheme_path).archive_action.build_configuration

  project = Xcodeproj::Project.open(project_path)
  target = project.targets.find { |item| item.name == scheme_name }
  UI.user_error!("Missing target #{scheme_name}") unless target

  build_configuration = target.build_configurations.find { |item| item.name == configuration }
  UI.user_error!("Missing build configuration #{configuration}") unless build_configuration
  bundle_id = build_configuration.resolve_build_setting("PRODUCT_BUNDLE_IDENTIFIER", target)
  UI.user_error!("PRODUCT_BUNDLE_IDENTIFIER is missing") if bundle_id.to_s.empty?

  {
    app_root: app_root,
    project_path: project_path,
    workspace_path: workspace_path,
    scheme_name: scheme_name,
    target_name: target.name,
    configuration: configuration,
    bundle_id: bundle_id,
    team_id: build_configuration.resolve_build_setting("DEVELOPMENT_TEAM", target),
    profile_name: build_configuration.resolve_build_setting("PROVISIONING_PROFILE_SPECIFIER", target)
  }
end
```

Inputs are the team ID, the full name of an installed `Developer ID Application` identity with its private key, and a team API key's `.p8` path, key ID, and issuer UUID:

```sh
export MAC_APPLE_TEAM_ID=ABCDE12345
export MAC_APP_SIGNING_IDENTITY="Developer ID Application: Example Company (ABCDE12345)"
export APP_STORE_CONNECT_API_KEY_PATH="/path/to/AuthKey_KEYID.p8"
export APP_STORE_CONNECT_API_KEY_ID=KEYID
export APP_STORE_CONNECT_API_ISSUER_ID=ISSUER_UUID

bundle exec fastlane mac release
```

If your entitlements require an installed Developer ID provisioning profile, pass its name with `export MAC_DEVELOPER_ID_PROFILE="MyApp Developer ID"`. Otherwise, leave it unset. The profile and signing identity must match the app's bundle ID and team.

Distribute the exported `.app.zip` under `dist/`. This ZIP contains the stapled app; no installer signing identity is needed.
