**Expo Desktop** <sup>[[github]](https://github.com/shirakaba/expo-desktop)</sup> <sup>[[youtube]](https://www.youtube.com/watch?v=D4yUa0-w69o)</sup> <sup>[[speakerdeck]](https://speakerdeck.com/shirakaba/expo-on-desktop)</sup> adds **best-effort macOS and Windows support** to Expo apps. It is an independent project by [Jamie Birch](https://github.com/shirakaba), not endorsed or maintained by Expo.

It consists of the `expo-desktop` CLI, plus several supporting libraries (like `expo-desktop-config-plugins`), that together allow you to create an app and run it for iOS, Android, Web, macOS, and Windows.

## Quickstart

After following the [prerequisites](/guides/prerequisites), create an app like so:

```npm
# Create the app.
npx expo-desktop@latest create-app

cd MyApp

# Generate the Xcode, Gradle, and MSBuild projects.
node --run prebuild
```

… then run your chosen target!

```sh
node --run ios
node --run android
node --run web
node --run macos
node --run windows
```
