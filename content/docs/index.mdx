Expo Desktop adds **best-effort macOS and Windows support** to Expo apps. It is an independent project by [Jamie Birch](https://github.com/shirakaba), not endorsed or maintained by Expo.

It consists of the `expo-desktop` CLI, plus several supporting libraries (like `expo-desktop-config-plugins`), that together allow you to create an app and run it for iOS, Android, Web, macOS, and Windows.

## Start here

```bash
npx expo-desktop@latest create-app MyApp
cd MyApp
npx expo-desktop prebuild --platform desktop
```

Then build and run the desktop target on its host operating system:

```bash
# On macOS
npx expo-desktop run macos

# On Windows
npx expo-desktop run windows
```

Native builds need Xcode on macOS or the React Native Windows toolchain on Windows. The [create an app guide](/guides/create-app) covers setup and the initial prompts.

## Know the boundaries

The supported version line is **Expo SDK 55 with React Native 0.83**. React Native, React Native macOS, and React Native Windows must share a compatible minor version, so the latest Expo SDK is not necessarily usable. See [version compatibility](/guides/create-app#why-expo-sdk-55).

Desktop support is best-effort. An Expo or React Native library working on iOS and Android does not establish that it works on desktop. EAS Build, EAS Submit, EAS Update, and Expo Go are not supported desktop workflows. Read [supported scope](/scope) before choosing dependencies or planning distribution.

For command options, see the [CLI reference](/cli). For the implementation, see [how Expo Desktop works](/how-it-works), or explore the [ecosystem](/ecosystem).
