## Expo on Desktop — Jamie Birch

[Expo on Desktop](https://birchdocs.tokyo/dev/talks#expo-on-desktop) is Jamie Birch's day-two keynote at App.js Conf 2026, presented on 29 May 2026. It introduces the project and the work involved in bringing the Expo workflow to desktop.

- [Watch the talk on YouTube](https://youtu.be/D4yUa0-w69o).
- [Read the slides on Speaker Deck](https://speakerdeck.com/shirakaba/expo-on-desktop).

## Spark

[Spark by Legend](https://legend.so/spark/) builds on top of Expo Desktop. Explore it for another project in the ecosystem taking Expo apps across mobile and desktop.

## Project and upstream resources

- [Expo Desktop on GitHub](https://github.com/shirakaba/expo-desktop) — source code, templates, releases, and issues.
- [React Native macOS](https://github.com/microsoft/react-native-macos) — the native macOS platform implementation.
- [React Native Windows](https://microsoft.github.io/react-native-windows/) — the native Windows implementation, toolchain setup, and platform documentation.
- [Expo SDK 55 reference](https://docs.expo.dev/versions/v55.0.0/) — the SDK version used by the current desktop template. Check desktop module support separately.
- [Expo CLI](https://docs.expo.dev/more/expo-cli/) — the standard mobile, web, and Metro workflow.
- [Continuous Native Generation](https://docs.expo.dev/workflow/continuous-native-generation/) — the model behind prebuild and regenerating native projects.
- [Expo config plugins](https://docs.expo.dev/config-plugins/introduction/) — background on repeatable native configuration; desktop modifications need desktop-aware plugins.
